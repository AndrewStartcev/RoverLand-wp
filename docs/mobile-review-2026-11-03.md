## Проверка

- PHP 8.3: синтаксическая проверка всех 77 PHP-файлов темы, ошибок нет.
- JavaScript: `node --check assets/js/main.js`, ошибок нет.
- HTTP-обход 248 URL: все 200, присутствуют H1, не обнаружены сообщения Fatal/Parse/Undefined PHP. В выборке 54 URL портфолио и 155 страниц с таблицами. Протокол: [mobile-crawl-2026-11-03.json](mobile-crawl-2026-11-03.json).
- Браузерные проверки на 390, 768, 1366 и 1920 px. Проверены главная, контакты, поиск и следующая страница, портфолио/7, /44 и видео /41, компания, акции и отдельная акция, Defender, диагностика Defender, продажа автомобиля. На проверенных узких шаблонах ширина документа не превышает доступную ширину.
- Подтверждены: центр карты и видимая метка с открытой карточкой на мобильном/десктопе; карта отдельной работы; второй уровень меню остаётся видимым при наведении на третий; форма записи из каталога; закрытие списка техцентров; воспроизведение видео компании и работы. Реальные заявки не отправлялись.
- Опубликованные CSS, JS и оба новых изображения побайтно сверены с локальными файлами.

HTTP-обход подтверждает доступность и базовую структуру, а не визуальную приёмку каждой страницы. Финальная клиентская приёмка остаётся за заказчиком.

## Развёртывание и откат

Перед изменениями свежая серверная копия темы сравнена с Git baseline: различий в отслеживаемых файлах нет. Резервная копия `/var/www/fastuser/data/rover-backups/archivenNWmj.tar.gz` хранится вне публичного каталога. Применены только файлы темы через FASTPANEL на dev. База данных, DNS, индексация и production roverland.ru не менялись.

Все четыре установочных ZIP перемещены за пределы web root; проверены ответы 404 для их бывших публичных URL и URL резервной копии. Откат — восстановление изменённых файлов из резервной копии или предыдущего Git commit 26ff705.
