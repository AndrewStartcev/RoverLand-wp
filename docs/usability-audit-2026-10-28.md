## Проверка

- PHP 8.3: синтаксическая проверка всех PHP-файлов темы.
- JavaScript: проверка синтаксиса main.js.
- `docs/check-usability.php`: сохранение Unicode, экранирования, всех цен без потерь/дублирования; неизменность таблиц без категорий; распознавание матричных категорий и сохранение услуг с пустыми ценами.
- HTTP-обход всех **188 опубликованных страниц** из HTML-карты: все 200; **155 страниц содержат таблицы**, **12 — категории прайсов**. Нераскрываемых строк категорий с пустыми ценами не осталось. Матрицы без категорий не сворачиваются целиком.
- Дополнительно проверены пустой поиск, 404 (HTTP 404 сохранён), одна форма продажи, контакты, главная, история, модели и разделы сервиса.
- В браузере: девять категорий Discovery 3, открытие мышью и Enter; отдельная проверка с отключённым JavaScript — «Комплексная диагностика» и цена 3800 доступны после штатного раскрытия. Скрипты после теста включены, тестовая вкладка закрыта.
- Карта: выбор Запада из карточки, выбранная карточка/описание и RL-метки; ошибок JavaScript в этой проверке не обнаружено.
- Адаптив: 390 px и диапазон шапки выше; мобильная почта 343 px внутри экрана 390 px, горизонтального переполнения нет. Окно техцентров находится внутри экрана (X: 19–359 при 390 px).
- Фото: проверены открытие dialog, подпись и закрытие. Реальные заявки и письма при проверках не отправлялись.
- Индексация dev-сайта остаётся закрытой. Основной домен roverland.ru, DNS, SSL и конфигурация сервера не изменялись.
