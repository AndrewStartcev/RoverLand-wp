## Применение и откат

Репозиторий темы на сервере: `wp-content/themes/rover`; корень WordPress: `/var/www/fastuser/data/www/rover.argokov.ru`.

```sh
git pull --ff-only
wp eval-file docs/check-model-revision.php --path=/var/www/fastuser/data/www/rover.argokov.ru
wp eval-file docs/apply-model-revision.php all apply --path=/var/www/fastuser/data/www/rover.argokov.ru
```

Повторное применение пропускает уже обработанные страницы. Перед первой записью сохраняются исходные значения ACF в серверной опции `roverland_model_revision_20261016_backup`. Дамп базы и секреты в Git не добавлялись.

Для восстановления содержимого конкретной страницы:

```sh
wp eval-file docs/apply-model-revision.php defender/diagnostika rollback --path=/var/www/fastuser/data/www/rover.argokov.ru
```

Для отката шаблонов использовать обратный коммит изменений этого пакета, затем обычное обновление темы. Точечный откат содержимого проверен; полный откат всех страниц не выполнялся.
