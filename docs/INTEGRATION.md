# Rover Land — правила интеграции WordPress

Базовая тема строится по принципам проекта `hollywood-wp`: шаблоны разделены от служебной логики, общие части вынесены в `template-parts`, PHP-функции лежат в `functions`, а ACF Local JSON хранится в `acf-json`.

## ACF

- `h1` и `h2` всегда создаются как обычные текстовые поля ACF.
- WYSIWYG используется для контентных фрагментов, где внутри идут обычные HTML-теги без специальных CSS-классов.
- Если верстка требует классы, карточки, иконки, ссылки, повторяющиеся элементы или отдельные параметры — используются структурные поля ACF: text, textarea, image, link, repeater, group, relationship и т.д.
- Не складывать размеченные дизайн-блоки в WYSIWYG.
- Все группы полей должны сохраняться в `acf-json`.

## Этапы натяжки

1. Сначала сохраняем HTML-структуру и BEM-классы исходной верстки.
2. Затем заменяем только контентные значения на WordPress/ACF.
3. Общие сущности выносим в CPT/таксономии только когда подтверждена повторяемость данных.
4. Миграцию старого Bitrix-контента делаем после утверждения структуры WordPress.
